# Canonical-E event audit ledger

This ledger records every run in the independent event audit. The source
fixtures live outside this repository under `fleet2/mclock-audit/audit_tb`;
their simulator output is evidence, not a generated repository artifact. A
row is a canonical-E suite row only when its source-shaped DUT is present in
`Examples/system-verilog` and `harness/sv/diff_test2.py --backend ecanon` runs
it. Race rows are recorded for review and excluded from value claims.
