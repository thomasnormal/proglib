# Generated unpacked FIFO

This source-shaped receipt covers a parameter-sized unpacked memory declared at module scope and written by one edge process per generated cell. The ordinary route retains the generate-for and each `mem[k]` target, then admits the independent constant cells under IEEE 1800-2023 §§7.4 and 27.4. The overlap guard remains conservative for symbolic indices.

Run `python3 Examples/system-verilog/sem2/generated_unpacked_fifo_e/check.py` for the extractor, ordinary canonical-E, Icarus Verilog 13.0, and Xcelium 24.03-s004 rows.
