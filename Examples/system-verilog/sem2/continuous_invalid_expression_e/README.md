# Retained invalid-expression refusal receipt

A source-shaped continuous assignment whose target is a typedef-backed variable
remains a named invalid-expression process at canonical-E execution. The
unchanged source rows match both pinned simulators, so the refusal is preserved
without inventing a fallback expression semantics.

This is the clean-room `blk_continuous_invalid_expression` shape. The
ordinary route keeps the named refusal and claims the simulator rows only for
the unchanged source.
