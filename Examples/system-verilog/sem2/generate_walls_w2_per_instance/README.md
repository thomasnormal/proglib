# Per-instance names for generate-for declarations

Canonical E now substitutes each active generate-block label and index into
source-shaped declaration and identifier names. The receipt covers scalar,
unpacked-array, sibling-loop, shadowing, and no-declaration controls from the
W2 family. It checks names such as `g[0].t`, `g[1].t`, and
`g[1].t[0]` under IEEE 1800-2023 §§27.4-27.6. The neutral packet supplies
simulator-side expected values and no oracle result is claimed for these
structural probes.
