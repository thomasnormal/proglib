# Fixed unpacked package aggregate parameter

This source-shaped fixture exercises IEEE 1800-2023 §§7.2 and 10.9 with a
fixed unpacked package parameter whose elements are packed structs. Canonical E
retains the package aggregate and resolves a parser-native runtime index,
including an unknown index that resolves to the four-state x vector. Icarus
Verilog 13.0 and Xcelium 24.03-s004 provide the source rows.
